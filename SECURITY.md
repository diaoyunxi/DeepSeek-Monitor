# Security Policy

## Supported Versions

The latest release on the `master`/`main` branch is supported with security updates.

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public issue.

Instead, please report it via GitHub Security Advisory:

1. Go to the **Security** tab of this repository
2. Click **Report a vulnerability**
3. Provide a detailed description of the issue

We will acknowledge receipt within 48 hours and aim to provide a fix within 7 days for critical issues.

## Security Best Practices

- Keep dependencies up to date (Dependabot is enabled)
- Never commit secrets, API keys, or credentials
- Use environment variables for sensitive configuration
- Review code changes carefully before merging

## Responsible Disclosure

We appreciate responsible disclosure. Please give us reasonable time to address the issue before making it public.
